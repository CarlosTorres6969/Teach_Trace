# Instrucciones para las actividades

Evalúa las entregas a partir de evidencia concreta.
Respeta los criterios de la rúbrica y los resultados de aprendizaje.
Considera las instrucciones específicas del docente para la actividad.
Explica las fortalezas y ofrece recomendaciones claras para mejorar.
Cuando falte evidencia, indícalo y deja la decisión final al docente.
